What it does

Every picture and film on this page was made in nouPix itself, with one project: four zones of geometry, red and white.

Zone 01 100% ●

01 / Map

Draw your fixtures, or import them

Lay out the installation as it is built: every pixel where it really sits.

  • Lines, matrices, circles, arcs and ovals, straight or curved paths and a pen
  • Import an SVG drawing of the building as fixtures or as a guide
  • Group, lock, align, rotate, resize, copy and paste
  • Pixel count, colour order and wiring direction per fixture
  • Lock a strip's pitch and its length sets the pixel count, like a real strip cut to length
  • Dot fixtures for PARs, wall washers and big pixel modules
Zone 02 4 zones · 7 layers ●

02 / Zones & layers

Split the stage. Stack the looks.

A zone is any part of the stage with its own content, scenes, playlists and level. The rings can pulse while the triangle spirals and the matrix runs a checkerboard, each on its own, all at once, from one computer.

Inside a zone, layers stack like in a video mixer: each with its own effect, shader, video, capture or stream, opacity and blend mode. Zones overlap too: the upper one covers the lower.

AlphaAddScreenMultiplySubtractLightenDarkenDifference
ZonesAs many as you need, anywhere on the stage, each with its own scenes, playlists and level fader.

Zone 03 100% ●

03 / Play

Effects, shaders, video, capture and streams

From slow washes for architecture to hard chases for a show, on any part of the layout.

  • 53 built-in effects, sorted by mood, use, look and motion
  • Your own ISF shaders, images and video: trim, loop, with or without sound
  • Window capture, for example from other VJ software
  • NDI and OMT streams in from Resolume, TouchDesigner, OBS and other computers, as a source on any layer
  • Macros: speed, intensity, saturation and two colours for every effect at once
Zone 04 100% ●

04 / Scenes

Store a look. Fade back to it

Build the show once, then play it by hand or let it run by itself.

  • Scenes per zone with crossfades; the fade time sits on each scene
  • Playlists of scenes with play times: in a loop, once, or handing over to another
  • Keys 1–9 play the scenes of the selected zone; a separate Scenes window for a second screen
  • X-Fader: one fader between two zones, with a live preview of each; Mix, Dip or Cut
  • Snapshots on scenes: each button shows what it plays
Zone 05 100% ●

05 / Patch

Patch once. Send Art‑Net or sACN

Drag fixtures onto controller outputs and the addresses follow.

  • Automatic addressing, node discovery and a DMX monitor
  • sACN (E1.31) unicast or multicast, with a priority so a lighting desk can take over
  • 16-bit fixtures, dimming curves, RGBW, gamma and colour trims
  • Highlight lights fixtures on site: Trace, Flood, Color check, Spotlight, Pixel finder
  • A CSV patch list for the install crew
Zone 06 learn ●

06 / MIDI

Learn your controller in a second

Press Learn, move a fader, click what it should move.

  • Master, blackout, the X-Fader, group dimmers, zone levels, scenes and playlists
  • Macros and any control of an effect; faders pick up where the slider is
  • Every mapping as a wire in the patch bay
  • Flash pads: a scene, a level or blackout only while held, as on a lighting desk
  • No controller at hand? A virtual one on screen
Zone 07 100% ●

07 / Remote

Hand a phone to the end user

The people who run the place get the buttons they need, not the mapping. Phones, tablets and other computers on the network log in with a role.

  • Remote: a simple page to play scenes and playlists and dim each zone, and the X-Fader when you choose
  • Operator: content, scenes and playlists; the mapping stays locked
  • Programmer: everything, with a password
  • The phone page installs like an app
  • HTTP triggers: show control, a Stream Deck, a script or a building management system plays scenes and sets levels with a plain web address
Zone 08 100% ●

08 / Look

Black for the show. White for daylight

The interface is black, so the light on the stage is the brightest thing on screen. One click turns it white for working outside.

  • Works offline: fonts and everything else come with the app
  • The output keeps running when the window is minimised or covered
  • Projects save to a .noupix file you carry to the site, with autosave
  • Media library and packages: one .noupixpkg file with the project and its images and videos, for another computer
  • Shows that start by themselves: a project opens when nouPix starts, and a scene or playlist plays when it opens. For show computers and Raspberry Pis

Run it from the source

On Linux and the Raspberry Pi, or on any computer, nouPix runs straight from its source: a small Python program serves the interface and sends Art-Net or sACN. Nothing to build.

You need git, Python 3.8 or newer and Chrome, Chromium or Edge. nouPix opens in its own window. Keep the terminal open while it plays: closing it stops the output. python3 noupix.py --help lists the options, for example --bind-ip to send from a specific network card.

Browse the code on GitHub ↗

terminal
$ git clone https://github.com/nouled-studio/nouPix.git
$ cd nouPix
$ python3 noupix.py
  nouPix 1.3.0
  Interface   http://127.0.0.1:8080/
On a MacOpen the .dmg and drag nouPix onto Applications. The app isn't signed yet: the first time, click Done on the warning, then System Settings → Privacy & Security → Open Anyway.
On WindowsRun the installer. SmartScreen may say it protected your PC: click More info → Run anyway. It adds nouPix to the Start menu.
On the networkAllow nouPix through the firewall on private networks when asked, or node discovery won't find your controllers.
